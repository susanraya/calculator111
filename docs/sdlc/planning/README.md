### PLAN-EPIC-001 · approved · source: planning:EPIC-001

Evaluate basic arithmetic (add, subtract, multiply, divide) one operation at a time, with decimal support and a clear error state for division by zero and overflow.

Scope excludes scientific functions, percentages, square root and memory keys for this version; all calculation uses standard browser floating-point precision.

**Related:** US-001, US-002, US-003, US-004

### PLAN-EPIC-002 · approved · source: planning:EPIC-002

Provide input and display mechanics: on-screen buttons and keyboard entry for digits/operators/decimal/equals/clear, plus a numeric display and clear control.

On-screen buttons cover digits 0-9, the four operators, decimal point, equals and clear; keyboard keys mirror the same behavior as the matching on-screen buttons.

**Related:** US-005, US-006, US-007

### PLAN-EPIC-003 · approved · source: planning:EPIC-003

Deliver the calculator as a free, responsive, single-page web app for anonymous general-public users, with no login, no payments, and nothing persisted between sessions.

Runs entirely in-browser; no accounts, billing or history are kept across page reloads or visits.

**Related:** US-008, US-009, US-010
